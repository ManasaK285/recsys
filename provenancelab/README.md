# ProvenanceLab — AI Content Provenance & TrustEval

**An end-to-end research and engineering starter for AI-content provenance, watermark verification workflows, robustness testing, and detector evaluation.** The project combines a Streamlit dashboard, FastAPI service, controlled text transformations, benchmark runner, evaluation metrics, tests, and Docker packaging.

> **Important scope note:** The current implementation uses a simple lexical demo baseline and a synthetic smoke-test benchmark. It is **not SynthID**, does not detect SynthID watermarks, and cannot reliably determine whether text was written by a human or generated by AI. The metrics below only verify that the evaluation pipeline runs; they are not evidence of real-world AI-authorship detection. Do not use this demo for academic discipline, hiring, moderation, or other consequential decisions.

## Features

- Streamlit dashboard for text analysis, transformation comparisons, and benchmark monitoring
- FastAPI endpoints: `/health`, `/verify`, and `/benchmark`
- Controlled text transformations, including original text, truncation, and light edits
- Evaluation metrics: precision, recall, F1, false-positive rate, and confusion counts
- Reproducible synthetic smoke benchmark with seed and CSV/JSON outputs
- Pytest suite and Docker packaging
- Detector adapter structure designed to be replaced by a supported, calibrated watermark detector

## Quick start (Windows PowerShell)

Python 3.11 or 3.12 is recommended for dependency compatibility.

```powershell
cd path\to\provenancelab
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install pytest
```

If PowerShell blocks activation, use the environment's interpreter directly:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install pytest
```

### Run the dashboard

```powershell
python -m streamlit run app\dashboard.py
```

### Run the API (in a second terminal)

```powershell
python -m uvicorn api.main:app --reload
```

Open `http://127.0.0.1:8000/docs` for interactive API documentation. Health check: `http://127.0.0.1:8000/health`.

### Run tests and benchmark

```powershell
python -m pytest -v
python experiments\run_benchmark.py
```

Using `python -m pytest` helps ensure pytest runs under the active Python interpreter. Benchmark outputs are written to `outputs\benchmark_summary.json` and `outputs\benchmark_rows.csv` (depending on the script configuration).

### Example API calls (PowerShell)

```powershell
$body = @{ text = "Furthermore, this example sentence is long enough to test the provenance demo pipeline." } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:8000/verify" -Method Post -ContentType "application/json" -Body $body

$bench = @{ samples_per_class = 30; seed = 42 } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:8000/benchmark" -Method Post -ContentType "application/json" -Body $bench
```

## Research reference: SynthID-Text

The project is inspired by research on watermarking language-model outputs. The key reference is:

**Dathathri, S., See, A., Ghaisas, S., et al. (2024). “Scalable watermarking for identifying large language model outputs.” _Nature_, 634, 818–823.** https://doi.org/10.1038/s41586-024-08025-4

- **Paper:** https://www.nature.com/articles/s41586-024-08025-4
- **Official reference implementation:** https://github.com/google-deepmind/synthid-text
- **Hugging Face overview and integration:** https://huggingface.co/blog/synthid-text
- **Google Responsible Generative AI Toolkit documentation:** https://ai.google.dev/responsible/docs/safeguards/synthid

The paper describes SynthID-Text, a text watermarking approach that modifies generation-time token sampling and uses statistical detection. It studies detectability, text quality, and practical efficiency. This repository is a separate educational project; it does not reproduce the paper's results and does not currently implement SynthID-Text.

## Moving from demo to SynthID-based evaluation

1. Review the paper and official implementation linked above.
2. Choose a supported model and follow the current Hugging Face Transformers documentation for watermark-aware generation.
3. Use a detector configured for the exact watermarking setup; do not assume arbitrary text or every model can be checked by one detector.
4. Implement a dedicated `SynthIDDetectorAdapter` while keeping the demo lexical baseline clearly labeled as a baseline.
5. Build a held-out benchmark of watermarked and unwatermarked examples with known provenance. Keep labels and provenance metadata out of detector inputs.
6. Calibrate thresholds against a stated false-positive target and report sample sizes, confidence intervals, and metrics by text length and transformation.
7. Evaluate truncation, light editing, paraphrasing, and translation. Report performance degradation rather than assuming watermarks always survive these transformations.

The official GitHub repository describes its code as a reference implementation and points to the Hugging Face Transformers implementation for production-oriented integration. Review each project's current documentation, license, and version requirements before integrating it.

## Responsible use and limitations

- A positive watermark result is evidence about a supported watermark, not universal proof of AI authorship.
- Failure to detect a watermark does not prove human authorship.
- Detection is probabilistic and can depend on text length, model, watermark configuration, and transformations.
- Keep private watermark keys/configuration out of source control.
- Do not use the toy baseline or uncalibrated scores for consequential decisions.
- Record model/version, configuration, dataset source and license, sample counts, thresholds, and limitations in every report.
