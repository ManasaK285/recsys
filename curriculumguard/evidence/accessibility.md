# accessibility
Starter note - verify and replace with vetted sources before relying on it.

In the US, public schools have accessibility obligations under Section 504 and the ADA, and the W3C WCAG guidelines are the common technical benchmark for digital content. AI tools adopted in classrooms should be checked against them, including screen-reader compatibility.

AI features such as text-to-speech, captioning, and writing support can help students with disabilities, so blanket restrictions may remove assistive supports. Universal Design for Learning (CAST) is a common framework for planning flexible access.
